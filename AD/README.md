# Active Directory Home Lab

## Overview
Built and configured an Active Directory environment using Windows Server in a virtualized home lab.

## Skills Demonstrated
- Active Directory Domain Services (AD DS)
- Organizational Unit (OU) Management
- User and Group Administration
- Domain Join Configuration
- Windows Administration
- Help Desk Troubleshooting

## Environment
- Windows Server 2022
- Windows 11 Client
- Ubuntu Client
- VirtualBox

## Domain Name
femilab.local
